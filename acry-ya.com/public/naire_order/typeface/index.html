製作について

彫刻可能なアクリル

  • アクリル板は最大600x450mm
  • 厚みは2mm～15mm

製作条件

  • 文字のみ（漢字カナ英数など）
  • 文字のみで水平横書き
  • 最大文字高さ30mm・最小文字高さ4mm

原稿データの作成方法

書体データが準備できる場合書体データが準備できない場合

既製書体（丸ゴシック体・明朝体）の横書きの場合は 【イラストレーター】又は【ワード】又は【JPG・GIF・PDF形式】のデータを下記要領にてご準備下さい。

  1. 1彫刻する板の四角い枠を表記し、縦横寸法を入れます。

    アートボードサイズで指定しないで下さい。

  2. 2彫刻する文字をレイアウトして、彫刻の縦横寸法を入れます。

    お持ちの丸ゴシック体か明朝体を配置して下さい。

    実際の彫刻は弊社準備の丸ゴシック体又は明朝体になります。

  3. 3彫刻位置の寸法を入れます（右図の点線は不要）。
  4. 4オーダーフォーム内の図面の添付にてデータをお送り下さい。

注意

  • Macでデータを作成された場合は、ファイル名に拡張子を入れて圧縮して下さい。
  • データに不備があった場合は、修正後に再度お送り頂く場合がございます。予めご了承願います。
  • 弊社使用フォントの都合上、文字の仕上がりサイズが指定サイズと異なる場合があります。
  • レイアウトデータが準備できない場合は、次の【書体データが準備できない場合】を参照の上、テキスト原稿にてご準備下さい。

オーダーフォームの「テキスト指定欄」に１～８の指定を記載して下さい。

  1. 1彫刻文字：アクリ屋
  2. 2彫刻板サイズ：横120mm
  3. 3彫刻板サイズ：縦60mm
  4. 4彫刻位置：左端から10mm
  5. 5彫刻位置：右端から10mm
  6. 6彫刻位置：下から20mm
  7. 7彫刻文字の高さ：10mm
  8. 8彫刻文字の全体幅：100mm

注意

  • 弊社使用フォントの都合上、文字の仕上がりサイズが指定サイズと異なる場合があります。
