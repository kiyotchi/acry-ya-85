製作について

彫刻可能なアクリル

  • アクリル板は最大600x450mm
  • 厚みは2mm～15mm

製作条件

  • アドビイラストレーターのデータが必要

    データが無い場合は製作不可

  • 最大名入れ面積50mm x 200mm
  • 最小線幅0.5mm

原稿データの作成方法

  1. 1彫刻する板の四角い枠を原寸で描き、縦横寸法を表示します。

    アートボードサイズで指定しないで下さい。

  2. 2彫刻する図や文字を原寸で板の希望位置に配置します。
  3. 3テキスト（文字）の場合は必ずアウトラインに変換して下さい。
  4. 4オーダーフォーム内の図面の添付にてデータをお送り下さい。

注意

  • データは全て原寸で作成して下さい。
  • テキスト（文字）はアウトラインに変換して下さい。
  • 他のアプリケーションで作成した配置画像は彫刻できません。
  • イラストレーター上の線を使用せず、塗りのみでデザインして下さい。【図1】。
  • アウトラインは重ならないようにして下さい【図2】。
  • データにレイアウト（板に対しての配置）が出来ない場合、切削データ準備費は「イラストレーターのロゴデータのみ」の価格になります。その場合はオーダーフォーム内の「ロゴ位置指定欄」に希望する配置場所の寸法を入力して下さい。
  • Macでデータを作成された場合は、ファイル名に拡張子（.ai）を入れて圧縮して下さい。
  • データに不備があった場合は、修正後に再度お送り頂く場合がございます。また、デザインよっては彫刻できない場合があります。予めご了承願います。
